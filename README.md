A from-scratch, dependency-free CommonMark + GFM parser (parse.js) that renders markdown exactly like marked 18.1.3 with default options — verified 720/720 on the practice set — and runs about 1.3x faster than marked. main.ts reads /input/cases.json and writes /output/html.json.

## Run it

```sh
MAKEFUN_INPUT_DIR=./practice/input MAKEFUN_OUTPUT_DIR=./out node --experimental-strip-types main.ts
```
